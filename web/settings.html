Jr Architect Settings

Account

Your sign-in, and the GitHub account the IDE uses to open, pull and push your repositories.

AI provider keys

Paste a key from any supported provider. Jr Architect works out which provider it belongs to, checks it once, and uses it for the coding agent, Build mode and Agent Studio. Keys are stored on this server only and are never shown again in full.

This server's keys are managed by its administrator. Ask them to add one, or set JR_KEYS_EDITABLE=true.

Appearance

Dark or light. The choice is remembered in this browser.
